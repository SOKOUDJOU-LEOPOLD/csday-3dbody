# CS Day Demo: Webcam to 3D Body

Student stands in front of the laptop camera, presses one button, and gets a spinnable 3D mesh of their body, reconstructed by Meta's [SAM 3D Body](https://github.com/facebookresearch/sam-3d-body) running on a GPU server.

Work in progress. Setup, run and event-day instructions will be filled in as milestones land.

- Environment: `scripts/setup_env.sh` (follows upstream `INSTALL.md`)
- Upstream code: `third_party/sam-3d-body` (git submodule, pinned)
- Checkpoints, tokens and photos are never committed.
